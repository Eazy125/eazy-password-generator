# 🔐 Password Generator

A secure, responsive password generator built with **HTML, CSS, and JavaScript**. It allows users to generate customizable passwords based on their preferred length and character types.

## 🚀 Features

* Generate random passwords instantly
* Choose password length from **8–64 characters**
* Include or exclude:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Symbols
* Guarantees at least one character from each selected category
* Uses the browser's `crypto.getRandomValues()` for stronger random number generation
* Copy generated passwords to the clipboard
* Password strength indicator
* Responsive design for desktop and mobile devices
* Input validation and error handling

## 🛠️ Technologies Used

* **HTML5** — page structure
* **CSS3** — styling and responsive design
* **JavaScript** — password generation and application logic
* **Web Crypto API** — secure random number generation
* **Clipboard API** — copying passwords
